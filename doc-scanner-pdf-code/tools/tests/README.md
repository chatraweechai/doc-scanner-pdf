# Browser tests — doc-scanner-pdf

ชุดทดสอบการทำงานจริงของเว็บแอปในเบราว์เซอร์ (Playwright + Chromium) — รันอัตโนมัติใน GitHub Actions
(`.github/workflows/tests.yml`) ทุกครั้งที่ push และ **ต้องผ่านทั้งหมดก่อนเผยแพร่เว็บไซต์** (`pages.yml` เผยแพร่เฉพาะ commit ที่ผ่าน → https://chatraweechai.github.io/doc-scanner-pdf/)

```bash
cd tools/tests
npm ci --ignore-scripts
npx playwright install --with-deps chromium   # ครั้งแรกเท่านั้น
node run-all.js                   # ทุกชุด
node run-all.js ocr searchable-pdf  # เฉพาะบางชุด
```

| ชุดทดสอบ | ตรวจอะไร |
|---|---|
| `detect` | ตรวจจับขอบกระดาษแม่นยำ (มุมคลาดไม่เกิน 1.5% ของเส้นทแยง) และไม่ครอปผิดกับภาพสแกน/ภาพที่กระดาษล้นกรอบ |
| `e2e` | ขั้นตอนหลักบนจอมือถือ: เพิ่มรูป, ครอปอัตโนมัติ/อิสระ, ฟิลเตอร์, แสง, หมุน, เรียงหน้า, กล้อง (อุปกรณ์จำลอง), สร้าง PDF, ชื่อไฟล์ปลอดภัย, CSP |
| `edge` | เปิดจาก `file://`, ไลบรารีโหลดไม่ได้ + ลองใหม่, ภาพใหญ่เกิน (decompression bomb), XSS ในชื่อไฟล์, ลบหน้าระหว่างประมวลผล, หน่วยความจำ WASM ไม่รั่ว, เบราว์เซอร์ไม่มี SIMD, ไม่ได้รับสิทธิ์กล้อง |
| `ocr` | ความแม่นยำ OCR ไทย+อังกฤษ (≥ 95%), สระอำ, คัดลอก/บันทึก .txt, แคช, เปลี่ยนภาษา, ยกเลิก, ไฟล์ OCR หาย, `file://` |
| `searchable-pdf` | PDF ค้นหาข้อความได้: ข้อความที่ดึงออกมาตรงเอกสาร, คำค้นหาไทย/อังกฤษ/ตัวเลข, ตำแหน่งตรงกับภาพ, มองไม่เห็น (render mode 3), ภาพเหมือนเดิมทุกพิกเซล, อักขระพิเศษ, หยุดกลางคัน, ไฟล์ OCR/ฟอนต์หาย |
| `formats` | รูป WebP และ HEIC/HEIF (libheif ใน Web Worker, โหลดครั้งเดียวเมื่อจำเป็น), หันภาพถูก, ตรวจจับขอบ, ไฟล์ HEIC เสีย/ปลอม, หลายไฟล์พร้อมกัน, สร้าง PDF, `file://` |
| `pdf-convert` | แปลง PDF → Word: ข้อความไทยตรงต้นฉบับทุกตัวอักษร (PDF จาก Chrome ทั้งฟอนต์เว็บที่ใช้ `/ActualText` และฟอนต์ระบบที่ใช้ PUA, ฟอนต์ TIS-620 รุ่นเก่า, หน้าหมุน), บรรทัด/ย่อหน้า/คอลัมน์/หัวเรื่อง, หน้าสแกนอ่านด้วย OCR (≥ 90%) และแจ้งให้ตรวจทาน, อ่าน ActualText ไม่ได้ → แจ้งเตือน; PDF → JPG: 96/150/300 dpi, ขนาดไฟล์ตามคุณภาพ, .jpg/.zip, เลือกหน้า, หน้า A0 ไม่เกิน 16 MP; รหัสผ่าน, ไฟล์เสีย/ไม่ใช่ PDF, XSS ในชื่อไฟล์, hook บันทึกไฟล์, หยุดกลางคัน, เปลี่ยน/ปิดระหว่างเปิดไฟล์, ลากไฟล์มาวาง, PDF.js โหลดไม่ได้ + ลองใหม่, `file://` |
| `i18n` | ภาษาไทย/อังกฤษ: ข้อความไทยทุกข้อความในโค้ดและ `index.html` มีคำแปล ไม่มีคำแปลค้าง ตัวแปรตรงกัน; เบราว์เซอร์ภาษาอังกฤษเห็นทุกหน้าจอเป็นภาษาอังกฤษ (หน้าหลัก แก้ไข ครอป กล้อง สร้าง PDF, OCR, แปลง PDF, ข้อผิดพลาด, เอกพจน์/พหูพจน์), ภาษาไทย/ภาษาอื่นเลือกถูก, ปุ่มเปลี่ยนภาษาและจำค่า, `file://` |
| `motion` | แอนิเมชัน: หน้าจอ/หน้าต่าง/ข้อความแจ้งเตือน/หน้าครอป/ภาพหน้าแรก, รายการหน้าเปลี่ยนทันทีขณะเงาของหน้าที่ลบจางหาย (ซ่อนจากโปรแกรมอ่านหน้าจอ กดไม่ได้) และหน้าที่เหลือเลื่อนเข้าที่, กดลบ/ย้าย/ลบทั้งหมดรัว ๆ ไม่มีอะไรค้าง, ตำแหน่งแถบล่างไม่เพี้ยน, โหมด "ลดการเคลื่อนไหว" ไม่มีแอนิเมชันและไม่วน |
| `cache-busting` | ทุกไฟล์ CSS/JS มี `?v=<commit>-<วันเวลาที่เปิด>`, ไลบรารีใช้ `?v=<commit>`, เปิดซ้ำได้ไฟล์ใหม่, หน้าเก่าในแคชโหลดใหม่ 1 ครั้ง (ไม่วนซ้ำ), `version.json` เสีย/ช้า, `publish-site.sh` เผยแพร่เฉพาะไฟล์ที่ commit แล้ว ประทับเลข commit ได้ผลเหมือนเดิมทุกครั้ง และไม่เขียนทับโฟลเดอร์ของ repo |

- ภาพทดสอบใน `fixtures/` เป็นภาพถ่ายเอกสารสังเคราะห์ที่รู้ตำแหน่งมุมจริง (`meta.json`) และข้อความจริง (`ocr-truth.txt`)
- ผลลัพธ์ (ภาพหน้าจอ, PDF) อยู่ใน `out/` (ไม่ถูก commit) — ใน CI ถ้าทดสอบไม่ผ่านจะอัปโหลดเป็น artifact `test-output`
- `fixtures/pdf-check.html` ใช้ pdf.js (`pdfjs-dist`) ตรวจ PDF ที่แอปสร้าง: ข้อความ ตำแหน่ง render mode และพิกเซล
  (ชุด `pdf-convert` ใช้หน้านี้สร้าง PDF ทดสอบด้วย Chrome เพราะไม่มี CSP ของแอป — ฟอนต์เว็บจึงโหลดได้)
- เบราว์เซอร์ทดสอบตั้งภาษาเป็นไทย (`locale: 'th-TH'` ใน `lib/harness.js`) — ชุดอื่นตรวจข้อความภาษาไทย ชุด `i18n` ตรวจภาษาอังกฤษ
- ทดสอบแบบไม่พึ่งอินเทอร์เน็ต: ฟอนต์ Google Fonts ถูกแทนด้วยไฟล์ว่าง ส่วนไลบรารีทั้งหมดอยู่ใน `doc-scanner-pdf/vendor/`
