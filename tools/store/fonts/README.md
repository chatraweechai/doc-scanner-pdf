# Noto Sans Thai (for the store images and the promo video)

The font Android uses for Thai (and the first font in the app's CSS), so the store images show the app as it looks on a
phone. Variable font (weights 100–900), the three subsets Google Fonts serves (thai, latin, latin-ext):

- Source: https://fonts.googleapis.com/css2?family=Noto+Sans+Thai:wght@100..900 (`fonts.gstatic.com/s/notosansthai/v29/`)
- Project: https://github.com/notofonts/thai — license: SIL Open Font License 1.1 (`OFL.txt`)
- `SHA256SUMS` — checked by `tools/store/build.js` before use
